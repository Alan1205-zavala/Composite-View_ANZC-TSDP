# Composite-View_ANZC-TSDP

Este repositorio esta hecho para dar un ejemplo de una pratica para un Composite view, hecho en VS Code con PHP, del alumno Alan Naed Zavala Chavez, para la clase de Temas Selectos de Programación.

El patrón de diseño Composite view es un patrón de diseño estructural que te permite componer objetos en estructuras de árbol y trabajar con esas estructuras como si fueran objetos individuales.

Solo ingresar la carpeta completa "Proyecto_mcpvw" en xammp/htdocs.. Abrir el navegador y poner localhost/Proyecto_mcpvw, y listo.
